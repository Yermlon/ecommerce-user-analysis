# 电商用户行为数据分析
## ✨项目简介
基于电商用户行为日志数据集，使用Python完成数据清洗、指标统计、用户转化漏斗、时段分布、用户复购、品类复购多维度分析，挖掘用户转化流失、用户粘性特征，输出运营优化建议。

## 🛠️技术栈
Python | Pandas | Matplotlib | Jupyter Notebook

## 📊分析内容
- 数据预处理：时间戳解析、脏数据过滤、衍生字段（hour）生成
- 基础指标：PV、UV计算
- 转化漏斗：浏览-加购-支付链路转化率分析
- 行为时序分析：用户浏览活跃时段分布
- 用户分群：基于购买次数划分首购/复购用户，计算整体复购率
- 品类维度：统计各品类复购情况，过滤小样本，挖掘高复购品类

## 📈核心产出
1. 识别核心流失节点：浏览到加购环节流失最严重
2. 用户流量集中在白天13-14点，18-20点为全天流量低谷，上午流量平稳，下午是用户活跃黄金窗口，平台可选择在13点前后上线活动、推送营销内容，低谷时段减少营销触达，降低打扰
3. 用户整体复购率偏低，平台以一次性购买用户为主，用户粘性不足
4. 筛选出高复购潜力品类，可针对性做复购召回运营
