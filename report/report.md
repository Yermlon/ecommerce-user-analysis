# 电商用户行为数据分析 - 分析底稿
> 数据集：UserBehavior.csv
> 字段说明
> 原数据集字段和标准命名颠倒：category_id 代表行为（pv/cart/buy/cart），behavior_type 代表商品品类ID
> 字段：user_id, item_id, behavior_type(品类), category_id(行为), timestamp

### 数据清洗
1. 时间戳转datetime，提取hour小时字段
2. 过滤非法时间、脏数据
3. 清洗后有效数据：987709条

### 分析模块 & 结果
1. PV/UV指标
PV = 885259，UV = 524837
2. 转化漏斗
浏览用户：490664｜加购用户：50774｜支付用户：19244
浏览→加购转化率：6.58%
加购→支付转化率：2.65%
浏览→直接支付转化率：2.28%
结论：流失主要发生在浏览→加购环节，其次加购后流失高。

3. 用户活跃时段
流量高峰：13-14点；低峰：晚间18-20点

4. 用户分群（首购/复购）
首购用户：18822，复购用户：422，整体复购率：2.19%
结论：平台以一次性首购用户为主，用户粘性弱

5. 品类复购分析
统计口径：按【用户+品类】维度统计购买记录，复购用户定义为在同一个品类下产生2次及以上购买行为的用户；品类复购率 = 复购用户数 / 该品类总购买用户数。
过滤规则：筛选购买用户数≥20的品类，剔除样本量过小带来的失真结果，取出复购率TOP10品类。

1. TOP10品类的复购率整体不高，最高品类复购率仅约4.76%，品类之间复购率梯度明显，第一名显著高于后面品类；
2. 大部分品类的复购水平偏低，说明平台多数品类偏向一次性消费属性；
3. 存在少数品类复购表现相对突出，具备做用户召回、复购运营的潜力。

### 踩坑记录
1. 一开始看错字段含义，把behavior_type当成行为，导致全部分析逻辑错误，后面核对样本才发现字段颠倒
2. 漏斗绘图逻辑bug：一开始漏斗第三阶直接取加购&支付用户，不是顺序流转人群，口径不一致，后面修正为三步交集
3. 品类复购出现100%极端值：因为单用户单品类样本，增加过滤条件buy_user≥20剔除小众品类
4. 绘图中文乱码问题，配置matplotlib字体
